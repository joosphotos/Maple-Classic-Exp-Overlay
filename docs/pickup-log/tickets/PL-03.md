# PL-03 The game's item list and name matching

**Blocked by:** nothing. **Blocks:** PL-07. **Size:** S.

## Why
Item lines (`Stirge Wing x1 earned. (Etc)`) carry free text. A name read letter by letter is only trusted when it
is a real item, the same way map names are put right against `assets/maps.txt` (`server/tools/make_maps.py`,
`maple_exp._clean_map_name` / `MapList`, `server/src/mapnames.js`).

## Do
1. `tools/make_items.py`: builds `assets/items.txt` (one name per line, with its inventory tab: Equip, Use, Etc,
   Set-up, Cash) from meowdb.com's MapleStory Classic item data, like `make_maps.py` does for maps. Read meowdb's
   terms first; the README credits meowdb for maps already, add items there. If the session can't reach meowdb,
   stop and say so in Results (don't invent names).
2. `pickup_items.py` (pure): `ItemList.load()`, `snap(text) -> (name, tab) or None`: exact match first, then only
   OCR-style slips (l/I/1, O/0, rn/m, a dropped or doubled letter) and only when one name is clearly closest
   (never a guess between two). Roman numerals and apostrophes as in `_fix_roman`.
3. `tests/test_pickup_items.py`: exact names, slips that must snap, near-ties that must not, names not in the list.

## Done when
`assets/items.txt` with a count in Results, the matcher and its tests, README credit; nothing downloaded at run
time (the list ships with the app).
