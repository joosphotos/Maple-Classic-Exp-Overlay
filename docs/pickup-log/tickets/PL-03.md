# PL-03 The game's item list and name matching

**Blocked by:** nothing. **Blocks:** PL-07. **Size:** S.

## Why
Item lines (`Stirge Wing x1 earned. (Etc)`) carry free text. A name read letter by letter is only trusted when it
is a real item, the same way map names are put right against `assets/maps.txt` (`server/tools/make_maps.py`,
`maple_exp._clean_map_name` / `MapList`, `server/src/mapnames.js`).

## Do
1. `tools/make_items.py`: builds `assets/items.txt` (one name per line, with its inventory tab: Equip, Use, Etc,
   Set-up, Cash) from meowdb.com's MapleStory Classic item data, like `make_maps.py` does for maps. Read meowdb's
   terms first; the README credits meowdb for maps already, add items there. If the session can't reach meowdb,
   stop and say so in Results (don't invent names).
2. `pickup_items.py` (pure): `ItemList.load()`, `snap(text) -> (name, tab) or None`: exact match first, then only
   OCR-style slips (l/I/1, O/0, rn/m, a dropped or doubled letter) and only when one name is clearly closest
   (never a guess between two). Roman numerals and apostrophes as in `_fix_roman`.
3. `tests/test_pickup_items.py`: exact names, slips that must snap, near-ties that must not, names not in the list.

## Done when
`assets/items.txt` with a count in Results, the matcher and its tests, README credit; nothing downloaded at run
time (the list ships with the app).

## Results

**Permission.** meowdb's terms (§4) forbid bots and scrapers without permission, and its `robots.txt` says to ask
first. The repo owner told the session that meowdb's owner agreed to this use (not seen in writing here). Before that,
the session fetched only the rules: the home page, `robots.txt`, `/terms`, `/privacy` and a few paths that answered 404.
After it, with a pause of 3 s between requests and a User-Agent naming the project: the item list `item-db/all` (used),
`item-db` and `maps/all` (looked at, not used), `sitemap.xml`, and 404 probes for the item list's address. The Content Reuse
Policy (`/reuse`) answered 403 to the session, so it was not read. The saved pages are **not** in the repo.

**Built.**
- `tools/make_items.py <saved item-db/all page>` (offline, like `make_maps.py`) writes `assets/items.txt`.
- `assets/items.txt`: **5,151 lines** (name, tab): Cash 2,994, Equip 1,187, Etc 332, Set-up 239, Use 399; 5,136 distinct names.
  The page lists 5,515 items; 364 fewer here because meowdb's notes were taken off (below) and equal names merged.
- `pickup_items.py` (pure, imports nothing from `maple_exp`): `ItemList.load()`, `ItemList.snap(text, tab=None)` and a
  module-level `snap(text, tab=None)` -> `(name, tab)` or `None`. Load 85 ms; a read 0.02 ms exact, 0.6 ms worst (full scan).
- `tests/test_pickup_items.py`: 46 checks, all pass, run by `tests/run_pickup_tests.py`.
- README credit (items added), `docs/CODEBASE.md` updated. `pickup_types.py` unchanged.

**How `snap` decides** (each step needs exactly one name to fit, else `None`; a looser step is never tried after a tie):
exact spelling, then same letters and digits ignoring capitals/spaces/punctuation, then the same after the font-reader
slips (l / I / 1 / | / ! are one letter, O / 0 one, `rn` = `m`; Roman-numeral last words as `_fix_roman`), then one dropped
or doubled letter (only in names of 6+ characters and with no digit in them or in the read). On all 5,151 real entries:
every one snaps to itself; ~29,000 one-letter drops/doublings never gave another item (28,651 snapped back, the rest
returned `None`).

**Decisions / things PL-07 and PL-02 must know.**
- **`tab` is optional.** Pass the tab the line named (`(Etc)`) when it was read: it narrows the list and makes ties rarer.
  A name picked up into several tabs (e.g. `Lollipop`: Equip and Cash; 15 such names) returns `(name, None)` without a tab.
  A tab that is not one of Equip/Use/Etc/Set-up/Cash gives `None`; `Setup` and `Set up` are accepted for `Set-up`.
- **Assumptions to check against real lines (PL-02 catalogue):** (1) the game writes the tab as `Set-up` (ticket's spelling);
  (2) meowdb's `Cash Equip` group is in the game's `Cash` tab; (3) meowdb's disambiguating notes `(Lv 10)` (1,223 names) and
  `(Alt)`/`(Alt 2)` (170) are not part of the game's name, so they are stripped. If any is wrong, change `TABS`/`LISTING_NOTE`
  at the top of `tools/make_items.py`, re-run it on the saved page, and the tests still hold.
- 7 pairs of names differ only in punctuation or spacing (`Blue Line Tank Top` / `Blue Line Tanktop`, `Red " + "` / `Red " - "`...).
  The exact spelling wins; a spelling that fits both equally gives `None`.
- A dropped letter can land on another real item (`Skull T-Shirt` minus T reads as `Skull -Shirt`, which fits `Skull Shirt`).
  This is inherent to a name list; the reader's quantity/tab checks and shadow mode are the guard.
- Names with accents (`Ü`, 8) keep the list's spelling; reads fold accents.
- Long names: the longest listed is 54 characters; whether the game wraps or cuts long names in the log is for PL-02.
- Re-run `make_items.py` whenever the game adds items; the list ships with the app and nothing is downloaded at run time.
