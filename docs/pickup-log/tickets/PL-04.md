# PL-04 The pickup log font

**Blocked by:** PL-02 (truth: which text is in which picture). **Blocks:** PL-05, PL-06, PL-07. **Size:** M-L.

## Why
Reader v2 reads text by drawing the game's own font and comparing pixels (`glyphs.py`; the fonts in
`assets/fonts_v2/`, built by `tools/make_font.py` from labelled frames). The pickup log is a new font: letters as
well as digits, proportional, several colours, and a dark shadow instead of the outline the other fonts have.

## Do
1. Measure from the crisp Ideal 1x frames (truth `log-20261029-131006`, each line at its first look, full
   strength): the shadow's exact shape (one pixel down-right? down and right? a full outline?), the fill colours
   (white, yellow, any other; flat or a gradient by row), each character's bitmap and advance, the space, the
   cell height, where the baseline and the right end sit relative to the anchor.
2. Extend the asset format and `glyphs.Font` without changing what existing fonts do:
   - `"fills": {"white": [[b, g, r] per row], "yellow": ...}` (several named fills; old fonts keep `"fill"`),
   - an outline rule for the shadow (for example `{"rule": "offsets", "offsets": [[1, 1]], "color": [...]}`),
   - `render(text, scale, ..., fill="white", alpha=1.0)`: alpha for fading lines (the line blended over the scene
     by alpha, shadow included).
3. `tools/make_font.py pickup <truth.json> [out.json]` builds `assets/fonts_v2/pickup.json` from the truth (no shape
   typed by hand, as for the other fonts). Re-runnable: PL-02b adds glyphs with more truth.
4. Check the drawing against the frames: at Ideal 1x every labelled line drawn at its place agrees with the real
   pixels (the agreement measure `glyphs.py` uses: F_MIN on sure-ink pixels); at Default (scale 1080/768, smoothed)
   the same lines drawn with the same smoothing model as `exp_font` agree too (fit and state the model: is the log
   scaled like the 1024 x 768 design area, but anchored to the window's right edge?).
5. List characters not seen yet. Until a glyph is in the font, PL-07 treats a line that needs it as unread.

## Done when
- `assets/fonts_v2/pickup.json`, the builder, the `glyphs.py` additions; `tests/test_pickup_font.py`: draws known
  lines and compares with small expected bitmaps made by the builder (no pictures from the recordings in the
  public repo; a test that reads recordings skips without `MAPLE_CAPTURES`).
- `tests/test_v2.py` still passes (existing fonts unchanged).
- Results: shadow rule, colours, the character set and what's missing, the Default model and its fit, the anchor
  geometry (right end and baseline vs the anchor in PL-02's truth).
