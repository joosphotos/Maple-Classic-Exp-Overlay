# PL-07 Reading a line

**Blocked by:** PL-04 (font), PL-03 (item list). Uses PL-02's truth and catalogue. **Blocks:** PL-09. **Size:** L.

## Do
`pickup_read.py` (pure): `read_line(img, anchor, row, colour_hint=None) -> (Line or None, why)` (`Line` in
`pickup_types.py`), reading the line whose top is at screen row `row` and whose right end is at `anchor.right`.
1. **Grammar first** (`docs/pickup-log/CATALOGUE.md` lists every kind): match each fixed phrase as one drawing
   (`You received EXP (+`, `Bonus EXP for PARTY (+`, `You have gained mesos (+`, ` earned. (`), in each colour,
   right-aligned with the number between `(+` and `)`. Then the number digit by digit (commas as the catalogue
   says), or for items: the tab in brackets, ` xN`, and the name letter by letter, snapped with
   `pickup_items.ItemList.snap` (an unsnapped name: kind "item" only if every letter read for sure, else None).
2. **On contrast, not exact colours:** compare on the shadow feature (pixel minus its shadow pixel) scaled by the
   line's strength, like `mesos_v2` reads over a see-through box. It must read at any strength from new down to
   about 70% (a line one look old or covered at its first look and read later).
3. **Fail closed:** a character that isn't clearly the single best fit (the `glyphs.py` rules: `F_MIN`, `MARGIN`),
   a glyph missing from the font, or a phrase that half fits: None with the reason. Never a guess.
4. **From PL-02 and PL-03** (CATALOGUE.md, their Results): never decide the kind by colour (EXP lines are white or
   yellow); a name tag drawn over part of a line makes it unread, not misread; a long item name is cut with `...`
   (`Halloween Can... x1 earned. (Etc)`): add to `pickup_items.py` a prefix match for a cut name (a result only when
   one item, in that tab, starts with the read prefix), with tests; `snap` returns `(name, None)` for a name in several
   tabs.
5. A known phrase but an unknown kind of line: kind "other" with its text, only when every character read.

## Done when
- `tests/test_pickup_read.py`: synthetic lines (PL-05's drawing if it is in, else the font's render) of every kind,
  every colour, strengths 1.0 to 0.7, scales 1x / 1080/768 / 2x, over made-up scenes: **0 wrong**, and all read
  except those made unreadable on purpose (covered digits, a glyph missing from the font) which give None.
- On the recordings (skips without `MAPLE_CAPTURES`): every truth line at its first look: 0 wrong; read or a stated
  reason (covered) for each one not read; the count in Results.
- Cost in Results: target under 2 ms a line at 1x, 4 ms at Default.
