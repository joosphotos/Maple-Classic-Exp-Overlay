# PL-01 Cloud test bench: the overlay's tests on Linux

**Blocked by:** nothing. **Blocks:** PL-10 (its tests touch `maple_exp`). **Size:** S.

## Why
Ticket sessions run in a Linux cloud container, where `import maple_exp` raises (`platforms.create_platform`
supports Windows and macOS only) and Tk/Pillow's `ImageTk` may be missing. So nothing that imports `maple_exp`
can be tested there (`tests/test_logic.py`, `test_screen.py`, `test_health.py`, `test_report.py`), and PL-10 has to
change `maple_exp`.

## Do
1. A test-only platform: `platforms/headless.py` (`HeadlessPlatform(Platform)`): no game window, no hotkeys, DPI
   96, data root from `MAPLE_EXP_DATA`. `create_platform()` returns it on Linux **only** when
   `MAPLE_EXP_PLATFORM=headless` is set; otherwise Linux still raises exactly as now. Windows and macOS unchanged.
2. The test scripts that import `maple_exp` set `MAPLE_EXP_PLATFORM=headless` before importing it (next to where
   they set `MAPLE_EXP_DATA`), so they run on Linux and nothing changes on Windows/macOS CI.
3. Find what else a Linux container needs and write it in `CLAUDE.md` under "Working notes" as exact commands.
   Known so far (2026-10-29): `apt-get update && apt-get install -y python3-tk` gives Tk for the system Python
   3.12 (not the default 3.13); Pillow from apt lacks `ImageTk`, so use a venv:
   `python3.12 -m venv --system-site-packages .venv` then `.venv/bin/pip install -r requirements.txt`. Tesseract:
   `apt-get install -y tesseract-ocr` if `test_ocr.py` should run. `test_ui.py` needs a display: try `xvfb-run`.
4. Run every test file on Linux and fix only what is Linux-specific *in the tests or the headless platform*. A test
   that can't run on Linux for a real reason (a Windows API) skips with a printed reason, on Linux only.

## Done when
- On Linux with the commands from `CLAUDE.md`: `test_logic.py`, `test_screen.py`, `test_health.py`, `test_v2.py`,
  `test_report.py` pass; `test_ocr.py` passes or skips; `test_ui.py` passes under xvfb or skips with a reason.
- Windows and macOS CI unchanged and green; the app itself never uses the headless platform.
- `docs/CODEBASE.md` mentions the headless platform.
